# Cloud Computing Reflection

Cloud computing is already part of my daily life even if I do not always notice it. Some of the cloud services I use regularly are Google Drive, Messenger, and Canva. Google Drive allows me to save my files online and access them anytime using my phone. Messenger helps me communicate with my classmates and friends, while Canva allows me to create presentations and school projects easily.

These services are examples of Software as a Service (SaaS) because I use the applications through the internet without installing or managing the servers. They also use the Public Cloud deployment model because they are available to millions of users over the internet. This makes them convenient, reliable, and easy to access from different devices.

Git and GitHub are also important tools in cloud computing. Git is used to track changes in files, while GitHub stores projects online and allows people to work together. If someone makes a mistake, previous versions can be restored, making collaboration much safer and more organized. Team members can also see who made changes and when they were made.

After learning about cloud computing, I realized that many of the applications I use every day depend on cloud technology. It helps me store files, communicate with others, and complete school activities more efficiently. Understanding Git and GitHub also taught me the importance of version control, especially when working on projects with other people. Overall, cloud computing has become an important part of my daily life, and learning about it will help me prepare for future studies and work in the technology field.
