# GCP Research

## 1. Brief Overview
Google Cloud Platform (GCP) is a cloud computing platform from Google. It provides cloud services for computing, storage, databases, networking, data analytics, and artificial intelligence.

## 2. Global Infrastructure
GCP has a global infrastructure made up of regions and zones. These locations allow organizations to deploy applications and services in different parts of the world.

## 3. Cloud Management Console
The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create, configure, monitor, and manage their cloud resources through the console.

## 4. Four Core Services

### Compute Engine
Provides virtual machines for running applications.

### Cloud Storage
Provides object storage for files and other data.

### Cloud SQL
Provides a managed relational database service.

### Google Kubernetes Engine (GKE)
Provides a managed environment for deploying and managing containerized applications using Kubernetes.

## 5. Three Advantages
1. Strong capabilities in Artificial Intelligence and Machine Learning.
2. Powerful data analytics and cloud computing services.
3. Global infrastructure that supports applications in different locations.

## 6. Typical Enterprise Use Cases
GCP can be used by enterprises for hosting applications, storing data, analyzing large datasets, developing AI and machine learning applications, and running containerized workloads.
