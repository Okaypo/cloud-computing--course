# Azure Research

## 1. Brief Overview
Microsoft Azure is a cloud computing platform from Microsoft. It provides cloud services that organizations can use for applications, storage, databases, networking, and other IT needs.

## 2. Global Infrastructure
Azure has a global infrastructure made up of regions and availability zones. This allows organizations to deploy applications and services in different geographic locations.

## 3. Cloud Management Console
The Azure portal is a web-based interface used to manage Azure resources and services. Users can create, configure, monitor, and manage their cloud resources through the portal.

## 4. Four Core Services

### Azure Virtual Machines
Provides virtual servers for running applications and operating systems.

### Azure Blob Storage
Provides cloud object storage for files and other unstructured data.

### Azure SQL Database
Provides a managed relational database service.

### Azure Virtual Network
Provides networking capabilities for Azure resources.

## 5. Three Advantages
1. Strong integration with Microsoft products and technologies.
2. Global infrastructure for deploying applications in different locations.
3. Scalable cloud resources that can support changing business needs.

## 6. Typical Enterprise Use Cases
Azure can be used by enterprises for hosting applications, storing data, running databases, supporting Microsoft-based environments, and building scalable business systems.
