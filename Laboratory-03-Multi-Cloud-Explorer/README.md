# AWS Research

## 1. Brief Overview
Amazon Web Services (AWS) is a cloud computing platform that provides many services through the internet. It helps businesses and organizations use computing resources without needing to maintain all the physical hardware themselves.

## 2. Global Infrastructure
AWS has a global infrastructure made up of Regions and Availability Zones. These locations allow AWS customers to deploy applications and services in different parts of the world.

## 3. Cloud Management Console
The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create, configure, and monitor cloud resources through the console.

## 4. Four Core Services

### Amazon EC2
Provides virtual servers for running applications.

### Amazon S3
Provides object storage for files and other data.

### Amazon RDS
Provides managed relational databases.

### Amazon VPC
Provides a virtual network for AWS resources.

## 5. Three Advantages
1. Wide selection of cloud services.
2. Global infrastructure for deploying applications around the world.
3. Flexible resources that can scale according to business needs.

## 6. Typical Enterprise Use Cases
AWS can be used by enterprises for hosting websites and applications, storing and backing up data, running databases, and building scalable business systems.
